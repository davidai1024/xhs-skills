# 小红书创作 Skills

从封面、标题、图文介绍到发布正文与话题标签，五个可以单独使用的 Codex Skill。

这套工具来自「职场咸鱼」实际内容创作中的反复修改：让读者看得懂，有继续看的理由，排版克制舒适，标题和文案忠于真实内容。它们辅助创作与检查，不自动发布，也不承诺流量效果。

## 五个 Skill

| 名称 | 显示名称 | 负责什么 |
| --- | --- | --- |
| `xhs-cover` | 小红书·封面 | Apple 风封面，固定排版参数、真实素材与缩略图检查 |
| `xhs-title` | 小红书·标题 | 先筛选适合内容的标题思路，默认给三个候选并推荐一个 |
| `xhs-tutorial` | 小红书·图文介绍 | 封面后的多页产品介绍、工具案例与操作教程，附读者和审美评审 |
| `xhs-content` | 小红书·正文 | 结合封面、图片、已选标题和标签写发布正文，补充图片之外的价值 |
| `xhs-tags` | 小红书·标签 | 查询真实话题、ID 和可见浏览量，核验样本关联，保留来源与局限 |

「图文介绍」输出图片轮播；「正文」输出发布时的文字说明，两者分工不同。可以先做好图文再补正文，也可以只调用其中一个，不必按固定顺序串联。

## 标题方法与全量研究

`xhs-title` 的入口包含完整主流程：理解素材 → 判定内容任务与初选方法 → 阅读对应方法与多个案例 → 写作 → 校验 → 按失败原因返工。

[方法索引](skills/xhs-title/references/title-method-library.md)提供12类主方法（每类4个案例）与问答、生活两类辅助方法（每类3例），共54个代表性原作。每类包含进入条件、分析步骤、分支、案例迁移边界、自拟改写与验收；模板资产提供54句分支模板、选题卡和交付模板。

[研究依据](skills/xhs-title/references/title-research.md)来自2026-11-12归档的5876条捕获文字全量语义判断，覆盖6业务品牌、5平台、26已确认平台账号；快手和视频号按研究范围排除。仍有采集差额，文字一致不等于同一视频，不能推导完整改题率或标题效果。

## 安装

下载本仓库 ZIP 并解压，将 `skills/` 下需要的文件夹复制到 `~/.codex/skills/`，保留每个文件夹内的资源与子目录。也可以把本仓库地址发给 Codex，让它安装指定 Skill。

已经装过旧版时：`content-title` 已更名为 `xhs-title`；备份后替换旧文件夹，避免两个版本同时生效。其余目录名保持不变，`xhs-tutorial` 的显示名称统一为「小红书·图文介绍」。修改安装后如未显示，可新开一次对话。

## 使用示例

```text
用 $xhs-cover，根据这些真实截图制作一张 Apple 风小红书封面。
目标读者是 AI / Mac 进阶用户，账号和头像使用我提供的素材。
```

```text
用 $xhs-title，先判断这篇内容适合哪些标题思路，给三个标题并推荐一个。
```

```text
用 $xhs-tutorial，把这个真实操作案例做成封面后的图文介绍。
保留我已选定的风格，检查正常手机阅读尺寸下是否看得懂。
```

```text
用 $xhs-content，结合这组图片和已选标题写小红书正文。
起因、过程和结果以我的实际经历为准，不编造体验。
```

```text
用 $xhs-tags，为这篇笔记查询相关的真实话题。
保留话题 ID、可见浏览量、来源和查询时间，区分未核验项。
```

## 环境与资源

- 适用于支持本地 Skills 的 Codex 环境。不同客户端可用工具不同，并非所有聊天窗口都具备电脑操作、截图或渲染能力。
- 封面和图文介绍需要实际排版、导出 PNG 与看图能力；可用 HTML/CSS、设计软件等。需要生成或编辑视觉素材时使用环境提供的图像工具，真实截图不冒充生成成果。
- 默认 Apple 风；macOS 使用系统字体，其他系统可用封面 Skill 随附的 Noto Sans SC（OFL 许可），替换后重新测量。未分发 Apple 字体。
- 随附「职场咸鱼」头像和案例预览是作者品牌示例。给自己的账号制作时换成自己的真实头像和名称；没有头像时可用纯文字落款。不要照搬案例身份或把配置截图说成运行结果。
- 标签查询需要可用的浏览器或数据来源；可能需要自行登录小红书。字段随页面变化，不能把旧选择器或历史浏览量当成当前事实。离线脚本只整理已经采集的证据。

## 验证边界

发布前检查五项 Skill 的目录与元数据、资源引用、相互引用以及标签证据整理脚本的关键边界。排版规范和评审清单仍需对每次真实产出执行；结构检查通过不等于所有内容效果、平台曝光或工具环境均已验证。

公开包不包含私人测试文件、会话记录、完整标题语料库或第三方历史封面截图。标题方法的研究摘要、矩阵统计与54个代表性原作拆解保留在 `xhs-title/references/`，不把历史样本自测等同于实际点击率验证。
