# 同素材盲测

1. **先冻结参照和素材。** 记版本、作品、官方发布平台、发布位、原题及采集日期。同一作品跨平台发布、标题更新或重新剪辑有疑义时，按转写、同一时点的画面和全片顺序查重。测过的作品转入旧题。开场和结尾的时间索引用于核对整篇范围。
2. **匿名起稿与复选。** 独立写手只看去发布标题的正式原片或官方字幕，必要的型号和事实从材料核实。历史例子避开目标作品及其跨平台版本。每部写 3 条同平台原生稿，由另一会话先看素材再选 1 条，并锁定原句。写手或复选者已经认得发布题时，记为旧题。较长的时间索引可以用 [字幕线索脚本](../scripts/find_source_cues.py) 定位，回看片内证据后再作决定。
3. **独立评审。** 将锁定稿和原题匿名打散，交给两位彼此隔离的评审。每项分别记通过、未通过或待核，附时间点和理由。两人对同一条首选五项均判通过，才计为全过。

| 验收项 | 具体核对什么 |
| --- | --- |
| 看点 | 读者为什么点开、正文实际会兑现什么。 |
| 句式与信息顺序 | 在直述、发问还是给前提，以及各截的作用和先后。 |
| 遣词 | 动词、主体称呼、量词、程度与语气。同义表达保住作用和强度即可。 |
| 留白 | 题面交代哪些已知事项，具体把哪个答案留给正片。 |
| 事实 | 写出的承诺、范围、数字、身份、体裁和真实程度。原题中独有的事实也单独核对。 |

4. **锁分再复盘。** 对照候选判断看点或词句有没有进入备选，确认失分在起稿、复选还是证据。已揭题的修复是旧题复测。有无补证的试验各自报告，补证材料只给正片点名、发布时已存在且能确认的证据，遮蔽目标发布题及其转述。新旧版本尽量在同一批新素材上并行检验，每位写手对每部作品只写一个版本。
5. **分别记录结果。** 新题、旧题、不同平台、跨语言及小红书格式各自记录。小红书稿在锁原生首选以后才适配。正式 99% 验收使用同一冻结版的至少 100 部未用于修订的独立新作品，报告样本数、逐项通过与失败。小样本、编辑自评及字数合规均各记各的结果。

字幕线索脚本接收带 `[分:秒]` 的纯文本。字数脚本接收一条或多条成稿。两者使用 Python 3 标准库。
