# 标题方法库：按判定查方法与多案例

本库承接 SKILL.md 的主流程。先判定内容任务，再读对应方法全文；同类至少对照两个不同分支的案例，素材复杂或方法交叉时再读第三、第四个。比较其成立条件与用户素材，不要求最终稿同时融合多种写法。

12类主方法每类4个原作，另有问答与生活两类各3个，共54个不同发布记录。它们是从5876条全量语义研究中选出的代表性教学案例，覆盖不同机制与边界；“经典”在此指适合讲解、可迁移，不是按播放量评出的最佳作品，也不替代全量统计。原文按已采集文字保留，未重新逐页核验全文、视频情节或产品效果。

每份方法都包含：适用与转向条件、具体分析步骤、分支选择、多案例逐条拆解、可填模板、自拟改写与验收。案例解释属于编辑判断，不能冒充原作者的内部策略或点击效果因果。

## 调用与案例迁移
1. 判定主任务，读选定方法，不按案例热门程度选。
2. 比较至少两个不同分支的原作：各自隐藏了哪个结果、交代了哪个对象，依赖什么证据或受众关系。
3. 为当前素材选一个主分支，必要时比较备选；不把四条模板都强行填一遍。
4. 用用户自己的事实写作，逐项核对原作专属的身份、数字、经历与结果没有被迁移。
5. 若仅通过换项目名就能套到任何作品，返回具体观看理由重选；若必须靠补造事实才能成立，换方法。
