# 苹果风教程排版

这是本用户选择的风格，非Apple官方规范。追求Apple产品介绍页的克制排字、大片纯色和单一主体；不需要添加苹果logo、设备样机或虚构系统界面来证明风格。

默认画布1080×1440，横向80px安全边距，正文宽920。背景#FFFFFF，标题#1D1D1F，次级正文#6E6E73，内容区#F5F5F7，蓝#0071E3只用于步骤编号、短操作提示和箭头。主要正文颜色保持足够对比。截图保留原色。

macOS优先系统字体：-apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif。英文呈现SF系统风格，中文用系统黑体。不随意打包Apple字体；共享给其他系统时使用合法可获得的字体，记录替代字体和重新测量结果。

建议正文页参数：

| 元素 | 坐标或样式 |
| --- | --- |
| 顶部组合 | x80 y80 h40；准确应用图标40×40，12px间隔；步骤文字28px/400 |
| 两行主标题 | x80 y208 w920；80px/600，行高88；近黑，不整行蓝紫高亮 |
| 副标题 | x80 y416 w920；32px/400，行高48 |
| 正文区域 | x80 y528 w920；底部不超过1280 |
| 提示词 | 32px/400，行高52；段落间20px；一层浅灰底，内边距28–40 |
| 次级说明 | 24–28px，行高36–44 |
| 账号 | 默认头像＋“关注职场咸鱼”；x80 y1368 w920 h32，整组居中；头像32×32圆形，间隔12px；文字22px/400，颜色#86868B；距底40px |

参数是起点，内容溢出时先删重复话、缩短句子或分拆页面，不压缩成难读小字。需要调整坐标时整套保持一致并记录。保持一个主要视觉层级，圆角24px，不叠阴影、描边、渐变和装饰标签。单页不用为了“高级”留出没有信息作用的大空洞。

原生截图文字过小时裁取关键片段，保持等比。深色截图可以在白底中保留，避免把截图外的整页也改成高对比大黑块。信息图尽量直接用关系和字表达，不用卡片套卡片。

可复用CSS的类名：page、top、title、subtitle、content、panel、flow、arrow、prompt、note、footer。插入真实内容与图片后必须实际渲染测量，不能把CSS参数当成成品通过证据。

账号头像使用 assets/zhichang-xianyu-avatar.png，来自用户现有个人网站的品牌头像。等比圆形裁切，不重绘。底部正文不超过1280，落款从1368开始，保留至少88px呼吸空间；缺少其他账号真实头像时用纯文字，不能生成冒充头像。
