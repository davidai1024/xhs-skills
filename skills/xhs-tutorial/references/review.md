# 教程的目标读者与审美评审

## 先检查主讲法与内容稿

先按 [观看目的与讲法](content-modes.md)核对整篇：主体交付是否与选定目的相符，有没有把展示或经历全部切成操作。先读未分页的内容稿，检查具体对象、例子、原因和动作是否完整；再读分页文字，检查为短句和版式压缩后有无歧义。没有文稿时从当前图中还原核心叙述，修补实际缺口，不为了流程形式重写用户已选好内容。只有标题整齐、抽象结论顺口，不算读者已经理解。进一步检查：开头是否让读者等太久才见到承诺的东西；每段是否回答了一个有来由的问题；具体例子有无输入、动作和结果；建议是否交代影响选择的代价。情绪句需有本篇具体材料支撑。不要用原作者经历或赞助套语替作者补内容。

## 单独检查表达

依[表达与节奏](expression.md)检查：作者在带看、解释还是评价，口吻是否前后一致又能随情境变化；抽象名词能否落成对象与动作；程度词是否匹配证据；连接词是否真的承接；长句是否逐步交代，短句是否承担判断；问句后有无及时回答。保留必要的口语限定，删掉堆口头禅、假改口和无对象的“你看”。这些是文字编辑判断，未听音频不报告真实停顿、重音或语速。

## 先读全套，再评单页

记录目标读者、已有知识和使用场景。先看180px模拟双列封面，检查是否有明确收益；再按正常顺序阅读360px正文和原图。图文教程还需要判断翻页之间是否连贯：代词是否有指代，上一页如何引出下一页。教学再检查准备、动作和成功条件；展示、经历、解释、互动分别看画面差别、变化、因果和回合，不统一用做得出打分。

正文小字不必在双列缩略图逐字清楚；但正常打开后的360px预览必须能舒服地阅读关键步骤。操作路径或截图小字承载核心步骤却不可辨时，裁切放大、改成准确路径示意或拆页。不能只因为原图好看就通过。

## 五个维度

1. **看得懂与主要目的达成**：每页能否复述新看到或理解了什么？教学才检查从哪里开始、具体说/点什么、需替换什么、如何知道成功。术语与所选受众匹配，不替进阶用户讲无关基础，也不跳过权限、版本等实际前提。
2. **想继续看与收藏**：封面是否说清收益？后续每页是否带来新信息，还是重复标题？真实案例、可复用提示词、明确验收能否帮助目标读者马上应用？不要靠堆页数、夸张标题或伪造数据增加吸引力。
3. **格调与舒适感**：逐条审查小字是否提供必要的新信息；重复主流程、解释设计形式或泛泛总结的文案删去。真实性与版本说明可放附带说明；实质影响操作的前提应融入正文步骤。检查实际字号、行长、段落、空白、配色和截图清晰度。苹果风是否体现在黑白灰比例、系统字形、克制蓝色和内容秩序，而不只是一句风格标签？比较整套一致性，不把模型审美当成普遍审美。
4. **可信与可复现**：配置页面只能证明配置内容，不能代替实际输出；展示实测成果时优先用真实产物；若页面目的是教读者验收，可以采用流程截图配验收清单，不强制改为产物截图。测试文件中的自述文字也不能独立证明自动化行为，应以实际文件及内容核验支撑。区分实测截图、示意、生成素材、可复用请求和读者环境条件。当前入口是否核对，权限是否必要且说清楚，标题是否超出真实能力，是否错误暗示普通聊天界面均可操作电脑？示例提示词中的冲突处理不等于已证明现有快捷指令支持该规则。
5. **整体节奏与交付**：封面承诺是否在正文兑现？是否过长、缺关键页或前后矛盾？有没有把参考链接、测试路径或用户隐私公开到图片？可复制内容是否有文本，页序与ZIP是否正确？

## 输出与修正

用“明确／需改／待验证”等结论，不强制分数。每个问题给出“页码和可见现象 → 对本次读者的影响 → 修改动作”。优先列最多三项；明显问题在制作授权内直接改，复查修改后的整套和关联交付物。

记录两层结果：
- 可观察证据：字号、截图来源、文字是否溢出、操作条件是否出现、页序。
- 受众推测：读者可能理解什么、是否想看或收藏。必须标成编辑判断。

交付简短结论，必要时另附详细评审。真实用户反应要实际询问；可让目标读者先复述内容和下一步，再问是否想实践及原因。不虚构访谈、眼动、平台测试或点击率提升。

## 保留选择与控制修改范围

优先按真实用户选择评价，不将“画面更统一”“卡片等高”“加入更多证据”直接判成更好。审美意见须落到可见问题；每条建议说明会改变哪个区域、为什么有帮助。验收指南评价动作和清单是否可照做，成果展示评价输出证据是否充分；不能混为一种页面。若用户明确选定或回选旧版，保留其构图，只处理文字溢出、错字、失真等具体问题。

局部修改后查看完整单页和全套缩略图，检查标题、说明、截图是否争夺主次，是否出现长短悬殊的截图块、元数据裁断或无意义空洞。等高等宽不是通过标准。先看真实成品，再描述检查结果；结构检查和视觉通过分别报告，避免宽泛地说全部通过。
