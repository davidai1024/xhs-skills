# 真实数据采集与门槛

## 路线选择

**默认：已登录浏览器。** 当前工具先读取文档与页面状态，正常打开小红书搜索、筛选、笔记和作者主页；不要求用户重新交出凭证。此路线已在标签任务实测，本技能于2026-11-13再次验证搜索卡片、原始发布时间与公开互动字段读取。一次成功不保证每次全量可用，仍需本轮实际返回。

**备选：配置好的数据接口。** [TikHub搜索笔记文档](https://docs.tikhub.io/420136398e0)提供最新、最多点赞等排序及一天／一周／半年筛选。文档查阅日期2026-11-13；本轮没有API密钥接入或付费调用。若仅有一周筛选，取回后仍逐条按原始时间过滤72小时。HTTP200不等于有有效笔记，示例返回不是实测。

**辅助：商业数据库与采集工具。** [千瓜功能对比](https://www.qian-gua.com/Home/AllPrice)列出笔记搜索、排行榜、更新和热词功能；[MediaClaw关键词爆款流程](https://www.mediaclaw.app/docs/viral-research/keyword-hits)说明平台筛选加采集过滤。上述为供应商文档核对，未登录购买或实测这些产品；不能声称有它们的实时库或已接通。平台公开热榜只做发现入口，不能替代相关笔记级数据。

## 浏览器实操

1. 新建研究标签页，保留用户原有创作草稿。读取当前浏览器文档，若有会话命名要求先命名。记录查询、排序、窗口与采集时间。
2. 按已确认领域与实际结果扩展少量词，先用“最多点赞＋一周内”发现，再用“最新＋一周内”找新样本，沿真实相关作者补查。菜单可能悬停显示：普通点击无效先观察，不盲点；仅在当前工具支持时使用文档中的鼠标移动能力，不改DOM触发菜单。收起后检查实际筛选状态与已更新结果，瞬间空列表不立即当零结果。
3. 当前观察到搜索卡片为`section.note-item`，公开属性`data-note-id`及`.title`、`.author .name`、`.time`、`.like-wrapper .count`可读。先检查当前DOM再使用，选择器不是永远有效。排除大家都在搜等非笔记卡、广告与重复ID；只存24位真实笔记ID，规范链接为`https://www.xiaohongshu.com/explore/{note_id}`，访问可能需重新搜索或登录。不要保存带会话参数的链接。
4. 打开候选原笔记读实际内容、作者和详情日期。若显示“编辑于”，单靠DOM不能确定创建时间。当前工具明确提供CDP时，先读能力文档，临时开启`Network.enable`并取事件游标；正常点击已观察到的笔记，仅读取此次实际产生的`/api/sns/web/v1/feed`响应。用`Network.getResponseBody`读取已发生响应，核对`data.items[].note_card.note_id`与打开笔记一致。不得重放签名请求、调用隐藏内部接口、遍历cookie或存储。
5. 已观察的公开字段包括`time`、`last_update_time`、`interact_info.liked_count/collected_count/comment_count/share_count`及作者字段。保存必要字段，对照页面标题与互动数，毫秒时间转换为用户时区。响应含点赞状态、关注关系等非必要字段时不保存。缓存无新响应不能借用上一篇；可对当前页作一次有理由的刷新，仍无数据记未核实，不猜时间、不从ID前缀推定发布时间。
6. 读取相关作者近期可比笔记用于基线时，不受候选72小时限制，但必须另标基线、不进入热点候选；说明发布时间长短、图文视频及内容差别，累计点赞的年龄偏差不能忽略。未取得基线不报异常倍数。再次采集的快照才可用于计算点赞增量，不能把两个搜索结果中的相同值当时间序列。
7. 每个数据来源记录采集时间和原始显示值。“赞／未返回”是未知，不是零；“万”是约数。结束关闭本次监听，按浏览器工具要求收尾。失去连接或验证码等阻断时记录已取得范围，不绕过访问控制，不无限重试。

## 固定证据交付

保存每次查询、排序、作者覆盖、有效笔记数、失败记录；按笔记ID保存原始时间、更新时间、采集时间、原始互动数字、内容摘要和来源。笔记中产品能力的说法只是作者主张，热点采集不等于已核验功能、成本与原创归属。

`scripts/build_evidence.py --input <JSON> --output <JSON>`整理采集数据、去重ID并检查近72小时时间与点赞门槛，格式见脚本说明。它**不联网、不采集、不判断内容相关性或高赞，不自动确认起量**。输出的`publication_evidence_gate`只表示证据完整且在时间窗内。

选题推荐还须在此基础上核对账号相关性、主题相同但作者独立、点赞在样本中的表现与可跟发角度。有多人发但多数低赞，须明确“存在跟进、高赞分化”，不能说普遍爆火；只有一篇已完整核实，不能交三篇已验证爆款。

## 实测中的关键反例

2026-11-13：“Codex 帮你的照片一张张分好类！”搜索卡片显示1天前、1.3万，详情显示编辑于1天前，另一次详情显示1.4万。没有取得原始创建时间，也没有同页可比快照，不认定三天内新发、不给精确增长率。

“Claude 大人，您管这叫网页小游戏吗…”实际匹配响应给出创建时间2026-11-10 15:47:10（上海），本轮采集2026-11-13 14:07，3200赞，符合当时72小时窗口。稍后复用必须重新计算窗口，历史成功不能证明当前仍在窗口内。不同作者同主题卡片可见25、260、13等点赞，不能用标题里的“全网爆火”替代指标。

上述是路径验证与反例，不是默认热点清单；公开skill不包含登录信息、会话链接或整份第三方内容。
